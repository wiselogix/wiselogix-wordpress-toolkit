# Contributing

Thanks for contributing to the Wiselogix WordPress Toolkit.

## Before Opening a Pull Request

- Test your code on a current WordPress version.
- Follow WordPress PHP coding standards where practical.
- Avoid unnecessary dependencies.
- Document what the snippet does.
- Explain compatibility requirements.
- Do not include credentials, API keys, client code, or private project information.

## Pull Requests

Please keep pull requests focused. One feature, bug fix, or improvement per pull request is preferred.

## Security Issues

Do not publish sensitive security vulnerabilities as public issues. Contact Wiselogix privately first so the issue can be assessed and fixed responsibly.
