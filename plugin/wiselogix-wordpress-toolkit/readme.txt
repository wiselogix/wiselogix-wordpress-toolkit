Practical WordPress development utilities maintained by Wiselogix Technologies.

== Description ==

A lightweight collection of reusable WordPress development utilities.

The initial release includes a utility for removing unnecessary WordPress emoji assets.

== Installation ==

1. Upload the `wiselogix-wordpress-toolkit` folder to `/wp-content/plugins/`.
2. Activate the plugin through the WordPress Plugins screen.
3. Test on staging before production use.
